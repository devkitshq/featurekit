# Featurekit Basic Example Website

Live browser application demonstrating **real-time SSE push updates** across all 4 core flag types:
- **Toggle (Boolean)**: `feature-toggle`
- **Text (String)**: `headline-text`
- **Number (Number)**: `discount-number`
- **JSON (Object)**: `theme-config`

Served automatically on `http://127.0.0.1:4000` by `examples/basic-example/server/server.js`.
